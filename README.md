# MilanAlbertzWebsite

Personal portfolio site for Milan Albertz.

## Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS
- i18next (multi-language)
- Deployed on Vercel

## Scripts

| Command | What it does |
| --- | --- |
| `npm run dev` | Local development server |
| `npm run build` | Production build |
| `npm run preview` | Preview the production build |
| `npm run lint` | Run ESLint |

## Project layout

- `src/components` — hero, about, projects, work experience, nav
- `src/pages` — trips, CGI projects, hobby projects, university app, privacy
- `src/locales` — translations
- `api` — Vercel API routes
